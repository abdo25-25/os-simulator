
# Futuristic AI-Powered OS Simulator

Welcome to the next generation of Operating System simulation. This project transforms a basic OS simulator into a cinematic, interactive, and AI-driven experience.

## 🚀 Core Features

- **Futuristic UI/UX**: Dark theme with neon accents, Orbitron typography, and glow effects.
- **Real-time Simulation Engine**: Dynamic CPU and Memory usage simulation with live updates.
- **AI Core Assistant**: An integrated AI that monitors system health, predicts overloads, and provides smart recommendations.
- **Hybrid Interface**: Seamless integration between a graphical dashboard and a hacker-style terminal.
- **System Stress Mode**: A "game-like" mode where you must manage heavy system loads to prevent a crash.
- **Modular Architecture**: Clean, scalable code structure split into logical modules.

## 📁 Project Structure

- `core/`: Global configurations and centralized system state.
- `gui/`: UI components, utilities, and main windows.
- `simulation/`: The heart of the system - real-time engine and stress mode logic.
- `ai_engine/`: AI assistant logic and specialized UI panel.
- `visualization/`: Advanced visual components like the futuristic dashboard.
- `terminal/`: Command-line interface logic and UI.

## 🛠 How to Run

1. Ensure you have `customtkinter` installed:
   ```bash
   pip install customtkinter
   ```
2. Run the main script:
   ```bash
   python main.py
   ```
